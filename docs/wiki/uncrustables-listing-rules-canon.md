## 1. Картинки — только реальные фото. НИКАКОГО выдуманного товара

**Правило владельца 2026-07-08, дословно:**

> «нам нельзя продавать выдуманный Uncrustables… картинки должны генериться
> 100% теми вкусами, которые есть, ну и на 95% они должны быть похожи на
> оригинал.»

**Подтверждено повторно 2026-08-10:** «чтобы не создавали выдуманные товары.
Чтобы название не было выдуманных товаров и картинок не было с выдуманными
товарами».

Следствия, обязательные к исполнению:

- Упаковка Uncrustables/Smucker's **НЕ рисуется нейросетью**. Главная картинка
  собирается композитом из **нетронутых пикселей реальных фото коробок донора**
  на чистом белом фоне (`buildCompositeWithQA`, 2200×2200).
- Каждая картинка проходит **QA-офицера** (`composite-qa.ts`, Claude vision на
  подписке, $0): реальные ли коробки, белый ли фон, все ли ожидаемые вкусы,
  нет ли выдуманного/искажённого текста, нет ли чужого логотипа. Отклонённая
  QA картинка **никогда не публикуется**.
- **Названия тоже без выдумок**: в тайтле только вкусы, которые реально есть в
  наборе, официальными названиями с упаковки.
- ИИ-путь остаётся только для **настоящих gift set** (не own-brand passthrough).

### Почему это не вкусовщина, а риск

Модель придумывает похожие вкусы и коверкает печатный текст на чужом товарном
знаке. Ночная волна 10-11 августа дала живые примеры на ИИ-рендерах: «Reduced
**Sugor**», «**BMUCKERS**», «Peanut **Batter**», бейдж «6» вместо «4»,
«KEEP **PROZEN**». Каждый такой кадр — изображение несуществующего продукта
Smucker's. Композит из реальных фото этот класс дефектов устраняет
**структурно**: там настоящие пиксели, портиться нечему.

### Цена вопроса (замер 2026-08-11)

| | ИИ-рендер | Композит реальных фото |
|---|---|---|
| Время на картинку | 2–5 мин | **10–13 сек** |
| Проходимость с 1-й попытки | ~50 % | **100 % (3/3, 25/25…)** |
| Дефекты текста | постоянные | отсутствуют физически |

## 2. Количества — только рациональные зоны кулеров

Из [[uncrustables-cooler-packing]] (владелец, 2026-07-22):

| Кулер | Рационально | Мёртвые зоны |
|---|---|---|
| S | **24 / 28 / 30** | 31–47 |
| M (22 qt) | **48–54** | 55–59 |
| L (27 qt) | **60–66** (нелюбимый, умеренно) | 67–89 |
| XL (47 qt) | **90–135** | >135 |

**Нижняя граница 24 — экономическая, а не только физическая.** Валидатор кода
пропускает наборы от 4 штук, но кулер и заморозка съедают экономику:

| Набор | Цена | За сэндвич |
|---|---|---|
| 8 шт | $52.99 | **$6.62** ❌ |
| 16 шт | $64.99 | $4.06 ❌ |
| 24 шт | $76.99 | $3.21 ✅ |
| 48 шт | $135.99 | $2.83 ✅ |

При рознице ~$1 за сэндвич наборы меньше 24 штук не продаются. **Генератор
рецептов обязан отсекать всё ниже 24.**

## 3. Цена — привязка к бестселлерам

`цена товара (без доставки) = (COGS + упаковка) × MARKUP`, где **MARKUP ≈ 2.35**
(усреднено с живых бестселлеров: 24шт 2.45–2.55× · 30шт 2.30× · 48шт 2.31×).
Доставка — **отдельной строкой** через frozen-шаблон, не в цене товара.

Контрольные точки: 30шт → $88 · 48шт → $138 · 90шт → $256.

**ROI считается на вложенные деньги** = товар + упаковка ([[walmart-studio-pricing-roi]],
владелец 2026-08-04): «Вложенные деньги это только товар плюс упаковка. Доставку
считать не надо, потому что доставку мы покупаем за безналичные деньги». Цель —
70 % ROI. Не путать с маржой: при бесплатной доставке 30 % маржи = 42 % ROI.

## 4. Текст листинга — бренд-голос

Полностью в `CLAUDE.md`. Кратко: без эмодзи, без промо-прилагательных
(ultimate/perfect/premium/best/amazing), без заявлений о продаже и доставке
(`ships frozen` ❌ → `Keep frozen` ✅), без health-claims, обязателен
curator-дисклеймер. Копия генерируется детерминированно
`buildListingCopy()` — без LLM.

## 5. Архитектурное расхождение, требующее решения владельца

Гейт подлинности (`uncrustables-main-authenticity.ts`, создан 2026-07-22)
**жёстко требует сцену с кулером**: `cooler_is_white_textured_eps`,
`cooler_lid_leans_behind`, ровно 4 гель-пака (2 внутри + 2 снаружи). Он
проектировался под ИИ-рендер кулера и **структурно не пропускает композит на
белом фоне** — а композит теперь канон по разделу 1.

Обойти это враньём в пруфе (заявить кулер, которого в кадре нет) **нельзя**:
пруф запечатывается и является доказательством для публикации.

**Нужно решение владельца.** Честный путь: добавить в схему наблюдения второй
вид сцены `product-on-white-composite`, где вместо геометрии кулера
доказывается происхождение пикселей — URL и sha каждого донорского фото,
план композита (сколько коробок какого вкуса) и вердикт QA-офицера. Это не
ослабление гейта: для композита доказательство подлинности **сильнее**
(реальные пиксели с прослеживаемым источником), просто доказывается другим
набором фактов.

До этого решения композитные листинги можно **стейджить** (SKU, UPC,
комплаенс), но не публиковать.
