## 1. Картинки — только точные товарные варианты. НИКАКОГО выдуманного товара

**Правило владельца 2026-07-08, дословно:**

> «нам нельзя продавать выдуманный Uncrustables… картинки должны генериться
> 100% теми вкусами, которые есть, ну и на 95% они должны быть похожи на
> оригинал.»

**Подтверждено повторно 2026-08-10:** «чтобы не создавали выдуманные товары.
Чтобы название не было выдуманных товаров и картинок не было с выдуманными
товарами».

Следствия, обязательные к исполнению:

- Production MAIN для frozen Uncrustables создаётся **GPT Image 2** по frozen
  contract v2.0: первая immutable reference — утверждённый cooler anchor, затем
  точные reviewed package-art references каждого выбранного товарного варианта.
- Модель не получает права придумывать упаковку. В prompt передаётся точный
  `frontPanelText`; flavor, product line, printed count, retailer-exclusive mark
  и другой package art должны соответствовать pinned reference.
- Рецепт обязан математически совпасть с изображением: количество видимых
  коробок/индивидуальных упаковок × реальный printed count = qty каждого
  компонента и общий count листинга.
- Каждая недетерминированная картинка проходит frozen QA-офицера
  (`frozen-main-qa.ts`, три голоса, fail-closed). Проверяются подлинность и число
  вариантов, крупный печатный текст, cooler geometry/branding, четыре gel packs,
  белый фон и отсутствие посторонних объектов. Отклонённая или непроверенная
  картинка **никогда не публикуется**.
- **Названия тоже без выдумок**: в title и атрибутах только точные варианты из
  рецепта; маркетинговый theme не заменяет фактический flavor.
- Детерминированный product-on-white composite остаётся исследовательским/
  историческим путём и не является production MAIN для этого frozen-класса.

### Почему это не вкусовщина, а риск

Модель может придумать похожий вкус и исковеркать печатный текст на чужом
товарном знаке. Ночная волна 10-11 августа дала живые примеры на rejected
рендерах: «Reduced
**Sugor**», «**BMUCKERS**», «Peanut **Batter**», бейдж «6» вместо «4»,
«KEEP **PROZEN**». Каждый такой кадр — изображение несуществующего продукта
Smucker's. Поэтому exact references сами по себе недостаточны: output bytes
обязаны пройти frozen QA и sealed approval.

### Цена вопроса (замер 2026-08-11)

| | GPT Image 2 frozen v2 | Устаревший composite-прогон |
|---|---|---|
| Время на картинку | 2–5 мин | **10–13 сек** |

## 2. Количества — только рациональные зоны кулеров

Из [[uncrustables-cooler-packing]] (владелец, 2026-07-22):

| Кулер | Рационально | Мёртвые зоны |
|---|---|---|
| S | **24 / 28 / 30** | 31–47 |
| M (22 qt) | **48–54** | 55–59 |
| L (27 qt) | **60–66** (нелюбимый, умеренно) | 67–89 |
| XL (47 qt) | **90–135** | >135 |

**Нижняя граница 24 — экономическая, а не только физическая.** Валидатор кода
пропускает наборы от 4 штук, но кулер и заморозка съедают экономику:

| Набор | Цена | За сэндвич |
|---|---|---|
| 8 шт | $52.99 | **$6.62** ❌ |
| 16 шт | $64.99 | $4.06 ❌ |
| 24 шт | $76.99 | $3.21 ✅ |
| 48 шт | $135.99 | $2.83 ✅ |

При рознице ~$1 за сэндвич наборы меньше 24 штук не продаются. **Генератор
рецептов обязан отсекать всё ниже 24.**

## 3. Цена — привязка к бестселлерам

`цена товара (без доставки) = (COGS + упаковка) × MARKUP`, где **MARKUP ≈ 2.35**
(усреднено с живых бестселлеров: 24шт 2.45–2.55× · 30шт 2.30× · 48шт 2.31×).
Доставка — **отдельной строкой** через frozen-шаблон, не в цене товара.

Контрольные точки: 30шт → $88 · 48шт → $138 · 90шт → $256.

**ROI считается на вложенные деньги** = товар + упаковка ([[walmart-studio-pricing-roi]],
владелец 2026-08-04): «Вложенные деньги это только товар плюс упаковка. Доставку
считать не надо, потому что доставку мы покупаем за безналичные деньги». Цель —
70 % ROI. Не путать с маржой: при бесплатной доставке 30 % маржи = 42 % ROI.

## 4. Текст листинга — бренд-голос

Полностью в `CLAUDE.md`. Кратко: без эмодзи, без промо-прилагательных
(ultimate/perfect/premium/best/amazing), без заявлений о продаже и доставке
(`ships frozen` ❌ → `Keep frozen` ✅), без health-claims, обязателен
curator-дисклеймер. Копия генерируется детерминированно
`buildListingCopy()` — без LLM.

## 5. Архитектурное расхождение закрыто frozen v2.0

Гейт подлинности (`uncrustables-main-authenticity.ts`) намеренно требует сцену
с кулером: `cooler_is_white_textured_eps`, `cooler_lid_leans_behind`, ровно
четыре gel packs (два внутри и два снаружи). Это соответствует production MAIN
contract v2.0 и не является blocker.

Batch-200 10–13 августа прошёл именно этот путь: GPT Image 2 + cooler anchor +
exact package references → frozen QA → sealed proof/manifest → Amazon. Все 200
submission получили `ACCEPTED`; выборка buyer/listing state подтвердила
BUYABLE/DISCOVERABLE. Ранее созданные 200 product-on-white composite были
отброшены и не являются опубликованными MAIN batch-200.

Создавать alternative proof, который заявляет кулер для изображения без
кулера, запрещено. Новый image mode потребует отдельного versioned contract,
машинного гейта и owner decision; до этого он не production-eligible.

## 6. Что уже живёт с GPT Image 2 cooler MAIN

- 22 листинга июльского забега (10 превью-партии + 12 пробного) были одобрены
  владельцем 2026-07-22.
- 200 листингов batch-200 опубликованы 10–13 августа по frozen v2.0.

Их нельзя массово «исправлять» generic PUT: для существующего Uncrustables ASIN
полный create-or-replace может удалить sale price/coupon. Любая последующая
правка идёт только exact-attribute surgical PATCH с pre-snapshot, validation
preview, ambiguity fence, offer-preservation и post-read verification.
