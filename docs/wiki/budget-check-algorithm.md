# 💰 Budget Check Algorithm *(АРХИВ / ОТМЕНЕНО)*

> **⛔ АРХИВ / ОТМЕНЕНО (решение владельца 2026-11-27):**
> Процентный лимит бюджета на этикетку **не применяется**. Выбор тарифа определяется дедлайном доставки, холодовым окном и компромиссом цена/скорость — см. единый канон [shipping-rate-selection.md](shipping-rate-selection.md).
> В коде `plan/route.ts` поле `budgetMax` всегда равно `null`. Таблица ниже сохранена исключительно как историческая справка из `MASTER_PROMPT v3.1` / legacy n8n.

## Историческая справка (не действует)

### Суть (архив)
Раньше предполагалась проверка стоимости shipping label против процентного бюджета: если label дороже лимита → СТОП («на ревью»).

### Абсолютный лимит (отменён)
Label cost > 50% от `(orderTotal + shippingCharged)` → СТОП для всех каналов/типов.

### Формулы по каналу/типу (отменены)
| Канал | Тип | Формула | Минимум |
|-------|-----|---------|---------|
| Walmart | Dry | 10% × margin + shippingCharged | $10 |
| Amazon | Frozen | 15% × margin + shippingCharged | $15 |
| Amazon | Dry | 15% × margin + shippingCharged | $10 |

Где `margin = orderTotal - shippingCharged`.
