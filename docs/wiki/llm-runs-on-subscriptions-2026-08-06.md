# Все модели — на подписке, платных API больше нет · 2026-08-06

> Связанные: [[codex-image-generation]], [[bundle-factory-scale-plan-2026-08-02]],
> [[walmart-lane-audit-2026-08-05]].

## Распоряжение владельца

Дословно: *«И вообще API не надо использовать. Мы говорили, что мы работаем без
API. У нас есть подписка OpenAI и Anthropic подписка есть. И забудь про API
навсегда. Про платные API токены забудь навсегда.»*

Значит: **никаких `ANTHROPIC_API_KEY` и `OPENAI_API_KEY`** — ни основным путём,
ни запасным, ни «только на один вызов». Оба ключа лежат в `.env` с нулевым
балансом, и это **правильное** состояние, а не поломка.

## Почему это вообще выглядело противоречиво

Claude Code работает на подписке Claude Max через OAuth, а `ANTHROPIC_API_KEY` —
отдельный счёт с поштучной оплатой. Одна компания, два кошелька. Первый оплачен,
второй пуст. Проверено живыми запросами: Anthropic отвечает
`credit balance is too low`, OpenAI — `no credits remaining`.

## Что нашлось по дороге, и это важнее самого распоряжения

`src/lib/text-gen/claude-text-worker.ts` ходил на `/text-claude` — эндпоинт,
которого **на боксе никогда не было**. Каждый вызов падал и по-тихому
проваливался в платный API, где денег нет. То есть **генерация текста листингов
не работала вообще**, и никто этого не видел, потому что запасной путь исправно
превращал мёртвый эндпоинт в невнятную ошибку.

Урок общий: молчаливый fallback прячет отказ основного пути. Поэтому его больше
нет — если воркер не отвечает, вызов падает и говорит, почему.

## Как устроено теперь

```
Vercel → HTTPS + Bearer → systemd codex-image-worker (104.219.53.204)
       → claude CLI на OAuth подписки → $0
```

Один воркер, четыре эндпоинта: `/generate` (картинки, ChatGPT-подписка),
`/analyze` и `/analyze-claude` (зрение), и новый **`/complete`**, он же
**`/text-claude`** — текст. `buildClaudeSubscriptionEnv` вычищает
`ANTHROPIC_API_KEY` из окружения дочернего процесса, поэтому даже случайно
оставленный на боксе ключ не превратит вызов в платный.

Клиенты: `src/lib/llm/subscription.ts` (простой `{prompt, system} → text|json`)
и `src/lib/text-gen/claude-text-worker.ts` (адаптер под форму Anthropic SDK, для
кода, который уже говорит `messages.create`).

| Место | Было | Стало |
|---|---|---|
| Интерпретатор свободного брифа | Anthropic API + OpenAI как fallback | подписка, без fallback |
| Генератор контента листингов | подписка → **платный fallback** (и он срабатывал всегда) | только подписка |

**Проверено живьём:** «сделай пять листингов супа Прогрессо по восемь банок,
маржа 25 процентов» → `search_query: "Progresso soup"`, 5 листингов, pack 8,
маржа 25 %, читаемый пересказ по-русски и честный список допущений. 4 секунды,
$0.

## Долг

18 файлов ещё ходят на платные API (зрение и текст). Список поимённо — в
`src/lib/llm/__tests__/no-paid-api.test.ts`, в константе `ALLOWED`. Тест

которое уже вычищено, обязано покинуть список. Список может только сокращаться.

## Обе подписки, а не одна (дополнение того же дня)

Владелец справедливо заметил, что подписок две и прикручены должны быть обе.

Что **уже существовало** и было переиспользовано без изменений: бокс, systemd,
nginx, общий Bearer-токен, `codex login` на ChatGPT Pro, `claude` на Claude Max,
эндпоинты `/generate` (картинки, Image 2.0), `/analyze` и `/analyze-claude`
(зрение). Двойной работы нет — инфраструктура подписок стояла с 2026-06-25.

Чего не было **ни на одной** линии — текста. Добавлено:

| Эндпоинт | Подписка | CLI |
|---|---|---|
| `/text-claude`, `/complete` | Claude Max | `claude -p --output-format json` |
| `/text-codex`, `/complete-codex` | ChatGPT Pro | `codex exec` |

`codex exec` печатает транскрипт, а не готовый ответ, поэтому промпт просит
обернуть ответ в маркеры `<<<ANSWER>>>…<<<END>>>`, и воркер вырезает ровно их.
Догадка «последний абзац и есть ответ» молча возвращала бы рассуждения вместо
ответа.

**Переключение автоматическое.** `completeWithSubscription` идёт по линиям
подряд: Claude Max первой (быстрее и надёжнее держит JSON-контракт), ChatGPT Pro
подхватывает всё, что первая отвергла, — включая исчерпанный месячный лимит.
Ошибку caller видит, только если отказались обе, и в ней названы обе. Линию
можно закрепить явно: `lanes: ["codex"]`.

Проверено живьём: `claude` — 5 с, `codex` — 7 с, обе $0; путь генерации контента
листингов идёт через ту же пару.

## Долг закрыт: платных вызовов в `src/` не осталось

Список `ALLOWED` в `src/lib/llm/__tests__/no-paid-api.test.ts` **пуст**. Тест
сторожит с двух сторон: новый файл с платным вызовом валит сборку, а имя,
которое уже вычищено, обязано покинуть список.

| Модуль | Куда переехал |
|---|---|
| Customer Hub: разбор писем, переводчик, A-to-Z, отзывы | обе текстовые линии |
| Walmart multipack: аналитик и полировка копирайта | Claude Max |
| Amazon: советник роста, генератор A+ | Claude Max |
| Очистка заголовков, размер упаковки (Procurement) | обе линии |
| `ai-vision.ts`, `claude.ts` | зрение: Claude Max, за ним ChatGPT Pro |
| Приёмка чеков | зрение Claude Max (картинка качается здесь, не на боксе) |
| Sourcing: `vision.ts`, `donor-catalog.ts` | три бесплатные линии; платный резерв удалён |
| Bundle Factory: визуальная проверка логотипов | Claude Max, без запасного пути |
| Панель настроек | показывает состояние двух подписок, а не наличие ключей |

Два удаления заслуживают отдельной строки, потому что оба прятали отказ:

- **Визуальная проверка логотипов** имела платный запасной путь, и когда баланс
  кончился, **каждая** сгенерированная картинка молча не проходила gate rule-6 —
  генерация при этом выглядела успешной.
- **Sourcing** держал платный «резерв» за двумя замками (`SS_VISION_FREE_ONLY`
  плюс owner-permit). Замки работали, но сам резерв больше не нужен.

Осталось пять **скриптов** разработчика (`scripts/check-model-updates.ts`,
`cogs-category-audit.ts`, `diag-multipack-genai.ts`, `walmart-audit-live.ts`,
`generate-uncrustables-gpt-image-2-previews.ts`). Они не выполняются в проде и
падают на пустом балансе; страж их пока не проверяет.
