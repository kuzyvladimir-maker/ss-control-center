# Все модели — на подписке, платных API больше нет · 2026-08-06

> Связанные: [[codex-image-generation]], [[bundle-factory-scale-plan-2026-08-02]],
> [[walmart-lane-audit-2026-08-05]].

## Распоряжение владельца

Дословно: *«И вообще API не надо использовать. Мы говорили, что мы работаем без
API. У нас есть подписка OpenAI и Anthropic подписка есть. И забудь про API
навсегда. Про платные API токены забудь навсегда.»*

Значит: **никаких `ANTHROPIC_API_KEY` и `OPENAI_API_KEY`** — ни основным путём,
ни запасным, ни «только на один вызов». Оба ключа лежат в `.env` с нулевым
балансом, и это **правильное** состояние, а не поломка.

## Почему это вообще выглядело противоречиво

Claude Code работает на подписке Claude Max через OAuth, а `ANTHROPIC_API_KEY` —
отдельный счёт с поштучной оплатой. Одна компания, два кошелька. Первый оплачен,
второй пуст. Проверено живыми запросами: Anthropic отвечает
`credit balance is too low`, OpenAI — `no credits remaining`.

## Что нашлось по дороге, и это важнее самого распоряжения

`src/lib/text-gen/claude-text-worker.ts` ходил на `/text-claude` — эндпоинт,
которого **на боксе никогда не было**. Каждый вызов падал и по-тихому
проваливался в платный API, где денег нет. То есть **генерация текста листингов
не работала вообще**, и никто этого не видел, потому что запасной путь исправно
превращал мёртвый эндпоинт в невнятную ошибку.

Урок общий: молчаливый fallback прячет отказ основного пути. Поэтому его больше
нет — если воркер не отвечает, вызов падает и говорит, почему.

## Как устроено теперь

```
Vercel → HTTPS + Bearer → systemd codex-image-worker (104.219.53.204)
       → claude CLI на OAuth подписки → $0
```

Один воркер, четыре эндпоинта: `/generate` (картинки, ChatGPT-подписка),
`/analyze` и `/analyze-claude` (зрение), и новый **`/complete`**, он же
**`/text-claude`** — текст. `buildClaudeSubscriptionEnv` вычищает
`ANTHROPIC_API_KEY` из окружения дочернего процесса, поэтому даже случайно
оставленный на боксе ключ не превратит вызов в платный.

Клиенты: `src/lib/llm/subscription.ts` (простой `{prompt, system} → text|json`)
и `src/lib/text-gen/claude-text-worker.ts` (адаптер под форму Anthropic SDK, для
кода, который уже говорит `messages.create`).

## Что переведено

| Место | Было | Стало |
|---|---|---|
| Интерпретатор свободного брифа | Anthropic API + OpenAI как fallback | подписка, без fallback |
| Генератор контента листингов | подписка → **платный fallback** (и он срабатывал всегда) | только подписка |
| Переписывание листингов | платный API | подписка |

**Проверено живьём:** «сделай пять листингов супа Прогрессо по восемь банок,
маржа 25 процентов» → `search_query: "Progresso soup"`, 5 листингов, pack 8,
маржа 25 %, читаемый пересказ по-русски и честный список допущений. 4 секунды,
$0.

## Долг

18 файлов ещё ходят на платные API (зрение и текст). Список поимённо — в
`src/lib/llm/__tests__/no-paid-api.test.ts`, в константе `ALLOWED`. Тест
сторожит две вещи: **новый** файл с платным вызовом валит сборку, и имя,
которое уже вычищено, обязано покинуть список. Список может только сокращаться.
