This directory contains owner-gated production evidence for exact immutable
`ProductTruthListingScope` imports.

promotion, provider or paid call, consumer activation, marketplace mutation,
procurement action, enrichment run, repricing, delisting or purchase.

must recheck the sealed schema fingerprint and precondition state, and must write its
report to a new immutable child directory.
